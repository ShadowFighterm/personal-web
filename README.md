# 🌐 Personal Website (HTML + CSS + JavaScript)

A simple **personal portfolio website** built using **HTML, CSS, and JavaScript**.  
This project demonstrates basic web development concepts, responsive design, and interactive elements without using any frameworks.  

---

## 🚀 Features
- Responsive design (works on desktop & mobile)  
- Homepage with introduction  
- About Me section  
- Portfolio / Projects showcase  
- Contact form (basic JavaScript validation)  
- Smooth scrolling & simple animations  

---

## 🔧 Prerequisites
To run this website, you only need a **modern web browser** (Chrome, Edge, Firefox, Safari).  
No external installations are required.
